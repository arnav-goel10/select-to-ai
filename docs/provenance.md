# Provenance and contribution

Select to AI began in the `arnav-prak/select-to-ai` repository. This repository is Arnav Goel's canonical personal publication of the extension and its current security architecture.

## Arnav Goel's work

- Product and interaction design updates for selected-text routing, provider selection, and side-panel workflows represented in this tree.
- Substantial Manifest V3 implementation and provider-integration work represented in this tree, including Gemini, Perplexity, dynamic context menus, shared provider configuration, and the current packaged release.
- Outbound-request policy, local credential handling, per-origin permissions, tests, and public documentation represented in this release.

## Attribution

Earlier repository contributors retain credit in the original repository history. This clean public release does not claim that its commit timestamps reproduce the original development chronology.
