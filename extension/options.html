Select to AI Settings

Welcome to Settings!
Select to AI sends selections to multiple AI assistants and can run a bounded browser agent. To get started, configure your API key in the Models & API tab on the left. You can also re-run the setup wizard anytime.

Behavioral Defaults
Auto-submit pasted selections Automatically submit the pasted prompt to shortcut assistants. Address-bar questions ("ai ..." in the URL bar) auto-send unless this is turned off.
Smart address-bar routing While you type after "ai" in the address bar, a small request to your configured model refines whether the input opens a site, asks the AI, or runs an agent task. Uses your existing key; suggestions stay instant either way.
Auto-Context link appending Appends active window URL & title to prompt selections automatically.
Assistant Opening Location Choose whether shortcut assistants open in the sidebar panel or a new tab.

Select to AI

Welcome to Select to AI

Send selected text to ChatGPT, Gemini, Claude, or Perplexity from the right-click menu; that part works out of the box.

✓ There is also an AI Browser Agent that can search, read pages, and fill forms for you.
✓ The agent is off by default and needs an API key from a model provider of your choice.
✓ This short setup connects a provider and turns the agent on. You can skip it and use the text shortcuts only.

Connect a Model Provider

Pick the gateway the agent should call and paste its API key. Keys are stored only in this browser's local storage.

Verify the Connection

Run a one-token test call so you know the key works before finishing. The test uses the provider's cheapest default model.

You're Set

Finishing enables the AI Browser Agent and saves your verified provider settings. Open it any time with Alt+A, the toolbar popup, or by typing ai + space in the address bar. Risky actions (payments, deletions, passwords) always stop for your confirmation.
