# Security Policy

## Supported version

Security fixes are applied to the latest release line.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, or user data. Use GitHub's private vulnerability reporting feature on this repository. Include affected version, reproduction steps, impact, and a minimal proof of concept where safe.

You should receive an acknowledgement within seven days. Please allow reasonable time for validation and a coordinated fix before public disclosure.

Never include a real provider key in a report. Revoke any key that may have been exposed.
